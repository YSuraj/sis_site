# AegisAI website — GitHub Pages upload

This folder is ready to publish as a static GitHub Pages website.

## Upload

1. Create a new repository on GitHub.
2. Upload **everything inside this folder** to the repository root. Keep the `assets` and `prototypes` folders intact.
3. Commit the files to the `main` branch.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. Wait for GitHub to display the published website URL.

The homepage is `index.html`. The `.nojekyll` file tells GitHub Pages to serve the static files directly.

## Before going public

- Replace `hello@aegisai.example` in `index.html` with the real business email.
- Replace the placeholder LinkedIn, YouTube, and X links in `index.html`.
- Rename the business if `AegisAI` is not the final brand name.
